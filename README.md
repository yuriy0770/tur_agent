## 📋 О проекте

**TravelHub** — это полноценный сайт туристического агентства, разработанный на Django. Платформа позволяет пользователям просматривать туры по категориям, искать по направлениям, оставлять отзывы и бронировать путешествия.

### ✨ Функциональность

#### Для всех пользователей:
- 🏝️ Просмотр каталога туров с фильтрацией по категориям
- 🔍 Поиск туров по названию, описанию, отелю и категории
- 📖 Детальная страница каждого тура с полной информацией
- ⭐ Отзывы и рейтинги к турам (после авторизации)

#### Для авторизованных пользователей:
- 👤 Личный кабинет с профилем
- 📝 Возможность оставлять отзывы и оценки
- ❤️ Добавление туров в избранное (в разработке)

#### Для работодателей (администраторов):
- 🛠️ Управление турами через админ-панель Django
- 📊 Просмотр статистики и отзывов
- 📝 Добавление/редактирование/удаление туров и категорий

## 🛠 Технологический стек

| Компонент | Технология |
|-----------|------------|
| **Backend** | Django 5.0, Python 3.11 |
| **Database** | PostgreSQL 15 |
| **Frontend** | HTML5, CSS3, Bootstrap 5 |
| **Аутентификация** | Django Auth + Custom User |
| **Поиск** | Django ORM с `Q`-запросами |
| **Отзывы** | Модель `Review` с рейтингом 1–5 |
| **Адаптивность** | Bootstrap 5 + медиа-запросы |
| **Фон** | Анимированное слайд-шоу из статических картинок |
